# Contributing to Fillin

## Phase Discipline
We develop Fillin in explicit, strict phases.
1. Understand the phase requirements.
2. Implement only the requested phase.
3. Test locally.
4. Review and fix.
5. Build.
6. Commit.

## Guidelines
- Do not implement future features.
- Simple reliable solutions over complex clever solutions.
- Keep changes tightly scoped. Do not make unrelated changes.
- Ensure all apps pass linting and typechecking.
